Verse Lock v3.16

The notification, rebuilt on the shape that has always landed.

What changed:
* The merged verse notification no longer uses the "ongoing" style, after that style kept going missing on a Galaxy Fold. It now posts exactly like the old daily verse test notification that always arrived, keeping the full verse text and the Previous and Next buttons.
* It posts on a brand new notification channel, so every phone gets the intended settings fresh.
* Send test now shows a result dialog with a short code (OK, BLOCKED, CHANNEL OFF, and others) instead of failing quietly, and asks for the notification permission on the spot if it is missing.
* Same signing key as always, so this installs over v3.15 with your favorites and settings kept.
